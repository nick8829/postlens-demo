统计口径与数据说明

互动率怎么算？

（点赞 + 评论 + 转发）÷ 浏览量 × 100%。这是本工具的三项互动率，不等于 X 官方的完整互动率。主题与总览按浏览量加权，不是帖子互动率的简单平均。

空值与 0 有什么区别？

未记录显示为「—」，不会当成 0。浏览量为 0 或任一互动项缺失时，该帖互动率不计算；相关分母旁会说明可计算的帖子数。主题图只比较有记录的浏览量。

数据从哪里来？

初次打开为明确标注的虚构示例。真实数据由你手动录入或从 CSV 导入，也可输入公开 X 用户名获取原创帖子。数据仅保存在当前浏览器，换设备不会同步；请定期导出 JSON 备份。

主题怎么排序？

按各主题单篇浏览量的中位数从高到低排，同分时有浏览记录的帖子更多者靠前。帖子少仅作提示，不影响排名或相关热点入口。平均浏览量和最高单篇作补充展示，不影响排序。未知浏览量不当成零，浏览量是获取时的累计值，可能受发布时间与事件热度影响。

AI 功能

当前版本生成含数据的复盘提示词，由你选择是否交给外部 AI。页面上的排名、主题初分与下一篇建议全部基于本地统计规则生成，未调用 AI 模型；它们是可验证的实验方向，不是增长保证。
